# Tee & Co. Website

A static, GitHub Pages-ready website for Tee & Co. Accounting | Tax | Advisory.

## Files
- `index.html` - premium homepage
- `services.html` - services overview
- `who-we-help.html` - audience/stage page
- `knowledge-base.html` - knowledge base foundation
- `insights.html` - insights foundation
- `contact.html` - contact page
- `styles.css` / `script.js` - homepage styling and motion
- `page-template.css` - internal page styling
- `.nojekyll` - GitHub Pages compatibility

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. GitHub will publish the site.

## Brand implementation note
The site intentionally follows the established Tee & Co. direction: deep navy, warm gold, ivory, editorial typography, flat colour, no gradients, no generic accounting imagery, no AI-human visuals and no visual clutter.
